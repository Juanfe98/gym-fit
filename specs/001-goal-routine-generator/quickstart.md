# Quickstart: Gym Planner

**Date**: 2026-05-26

---

## Prerequisites

- Node.js 20+
- npm 9+
- RapidAPI account with ExerciseDB subscribed (free tier sufficient)

---

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env — set EXERCISEDB_API_KEY=your_rapidapi_key_here

# 3. Fetch exercise data (one-time, or after adding new exerciseDbIds to routines)
npx tsx scripts/fetch-exercises.ts

# 4. Start dev server
npm run dev
# → http://localhost:4321
```

---

## Build

```bash
npm run build
# Output: dist/  (static, deployable to Vercel)
```

**Note**: `exercises.json` is committed — CI/CD does not re-fetch. Run
`npx tsx scripts/fetch-exercises.ts` manually only when adding new exercise IDs to
routines. The script skips the fetch if the file already exists and is non-empty.

## Project Structure

```
src/
  data/
    routines/           ← Edit here to change routine content (manually authored)
    exercises/          ← Auto-generated by fetch-exercises.ts — commit this file
  pages/
    index.astro         ← Homepage: goal selector
    routine/[goal].astro
    exercise/[id].astro
  components/
    GoalCard.astro
    RoutineDay.astro
    ExerciseCard.astro
    MuscleDiagram.astro
  services/
    exercisedb.ts       ← ExerciseDB integration (build-time only)
    muscle-map.ts       ← ExerciseDB muscle string → SVG element ID mapping
  assets/
    muscle-diagrams/    ← front.svg, back.svg (MIT-licensed)
  styles/
    global.css          ← Tailwind @theme tokens + global styles
scripts/
  fetch-exercises.ts    ← Populates src/data/exercises/exercises.json
```

---

## Editing Routine Content

1. Open `src/data/routines/{goal}.ts`
2. Edit `rationale`, `formCues`, `commonMistakes`, or `rationale` fields
3. To add a new exercise: find its ExerciseDB ID via the API, add `exerciseDbId` to the
   `ExerciseRef`, then re-run `npx tsx scripts/fetch-exercises.ts`
4. Run `npm run build` — must pass with zero TypeScript errors
5. Verify visually at 375px viewport width

---

## Deployment (Vercel)

1. Connect repository to Vercel
2. Set `EXERCISEDB_API_KEY` in Vercel → Settings → Environment Variables (Production + Preview)
3. Build command: `npm run build`
4. Output directory: `dist`

The fetch script consumes **1 of 500 free-tier monthly requests** per deploy.
